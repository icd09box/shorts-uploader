쇼츠 업로드 도구

운영자 본인의 유튜브 채널에 쇼츠 영상을 올리기 위해 만든 개인용 도구입니다. 운영자의 컴퓨터에서만 실행되며, 다른 사람에게 제공하는 서비스가 아닙니다.

하는 일

  • 운영자가 만든 영상을 운영자 본인의 유튜브 채널에 올립니다.
  • 올린 영상의 조회수 같은 통계를 읽어 옵니다.

Google 계정 사용

이 도구는 YouTube API 서비스를 사용합니다. 운영자 본인의 Google 계정으로만 로그인하며, 요청하는 권한은 영상 업로드와 채널 통계 읽기입니다. 자세한 내용은 개인정보처리방침과 서비스 약관에 있습니다.
