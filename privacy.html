개인정보처리방침

시행일: 2026년 11월 25일

쇼츠 업로드 도구(이하 "도구")는 운영자 본인의 유튜브 채널에 영상을 올리는 개인용 도구입니다. 운영자 외의 사용자가 없으며, 다른 사람의 개인정보를 수집하지 않습니다.

접근하는 정보

도구는 YouTube API 서비스를 통해 운영자 본인의 채널에 대해서만 다음 정보에 접근합니다.

  • 영상 업로드에 필요한 채널 식별 정보
  • 올린 영상의 조회수, 좋아요 수, 댓글 수 같은 통계

이용과 보관

  • 위 정보는 영상을 올리고 성과를 확인하는 데에만 씁니다.
  • Google 로그인으로 받은 접근 권한 정보는 운영자의 컴퓨터에만 보관하며, 외부 서버로 보내지 않습니다.
  • 어떤 정보도 제3자에게 제공하거나 판매하지 않으며, 광고에 쓰지 않습니다.

권한 철회

도구에 준 접근 권한은 Google 계정의 보안 설정에서 언제든 철회할 수 있습니다. 철회하면 도구는 더 이상 채널에 접근하지 못합니다.

관련 정책

도구는 YouTube API 서비스를 사용하므로 Google 개인정보처리방침이 함께 적용됩니다.
